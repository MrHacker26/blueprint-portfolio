# Blueprint Portfolio

Personal site for Tarun Joshi, Senior Full Stack Engineer.

Visual language: blueprint engineering. Dark navy, Geist, cyan signal. Case studies and live benches, not a template.

## Run

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
bun run build
bun run start
bunx biome check
```

## Stack

Next.js 16 App Router, React 19, TypeScript, Tailwind v4, Bun, Biome.

Copy lives in `src/lib/site.ts` and `src/content/`. Components render data.
